# MK1 Brainstorming

This directory captures exploration before it becomes a contract.

Nothing here overrides `design/`, `arch/`, or accepted ADRs. Useful findings are promoted explicitly rather than silently copied into implementation.

## Current artifacts

- `PRODUCT_THESIS.md` — what MK1 is and is not.
- `USER_JOBS_AND_PRINCIPLES.md` — user jobs, experience constraints and product principles.
- `MK0_TO_MK1_RECONCILIATION.md` — keep/change/remove/defer map from the existing system.
- `DECISION_CLOSURE.md` — questions that had to be resolved before MK1 could become build-ready.
