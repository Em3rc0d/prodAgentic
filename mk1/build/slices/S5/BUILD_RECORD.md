## Objective

Convert the certified immutable S4 visual intent into product-owned render bytes without transferring text authority to the renderer.

Canonical flow:

```text
VisualSpecV1
+ exact ContentSpecV1
+ exact DesignProfileV1
        ↓
RendererPort
        ↓
ChromiumRendererAdapter
        ↓
AssetStore
        ↓
owned bytes + SHA-256 + Asset records
        ↓
ContentRevision asset_refs
        ↓
Review preview
```

S5 stops before semantic/visual QA authority. S6 owns QA and automatic recovery. S5 may perform deterministic render-integrity checks required to prove its own output (dimensions, page count, file existence, digest integrity), but it must not claim `REVIEWABLE` or QA success.

## AssetStore contract

The filesystem V1 adapter must implement the frozen port semantics:

```text
put(bytes, metadata) -> storage_key + sha256
get(storage_key) -> bytes
exists(storage_key)
verify(storage_key, expected_sha256)
delete(storage_key)  # governed retention only; not exposed as normal S5 API
```

Security/integrity rules:

- storage keys are generated by the adapter; callers never concatenate arbitrary filesystem paths;
- keys are tenant/revision scoped and normalized;
- traversal / absolute paths / symlink escape fail closed;
- writes use temp file + fsync + atomic replace when supported;
- SHA-256 is computed from owned bytes after read-back;
- duplicate deterministic writes are idempotent only when bytes/digest agree;
- asset root restart must preserve exact bytes and hashes.

## Copy authority

Renderer resolves `TextBlockV1.copy_ref`, `MetricBlockV1.copy_ref/label_ref` and `DiagramBlockV1.label_refs` exclusively from the exact persisted `ContentSpecV1` bound to the revision.

Rules:

- unknown reference -> fail before render;
- critical text cannot come from renderer literals;
- renderer receives resolved immutable page data, not freedom to rewrite editorial copy;
- `render_input_digest` binds VisualSpec + ContentSpec + DesignProfile + resolved page payload.

## State transition

Entry:

```text
GenerationRun.VISUAL_PLANNING
ContentRevision.DRAFT
visual_spec_ref != null
asset_refs == ()
qa_report_id == null
```

S5 successful render:

```text
GenerationRun.VISUAL_PLANNING -> RENDERING -> QA
ContentRevision.DRAFT -> QA_PENDING
asset_refs = exact immutable AssetV1 IDs
qa_report_id remains null
```

S5 does **not** set `REVIEWABLE`; S6 owns that transition.

Failure:

- renderer/AssetStore failure must not alter ContentSpec/VisualSpec authority;
- partial unbound bytes/assets may remain as diagnostic lineage but must not be attached to the revision;
- retry must be able to recover or deterministically reuse the same successful immutable asset set without corrupting revision lineage;
- failure is observable with a safe failure code and exact stage.

## Rollback

- keep `MK1_RENDER_WORKER=false` to disable S5 authority;
- S4 VisualSpec remains certified and usable after S5 rollback;
- do not delete existing asset bytes during rollback;
- no destructive migration is authorized in S5.

## Known non-claims

S5 does not certify:

- semantic/claim QA;
- visual model QA or automatic clipping recovery;
- `REVIEWABLE` state;
- human approval;
- export, scheduling or publication;
- Redis/outbox worker transport;
- generated-image provider semantics unless separately implemented and certified.

Those remain S6+ authority.
