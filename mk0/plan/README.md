# MK0 Plan Map

MK0 did not maintain one canonical design/dependency graph. Delivery intent is reconstructable from sequential PR change records such as `PR-RUN-*`, `PR-APPROVAL-*`, `PR-PROFILE-*`, `PR-PUBLISH-*`, `PR-SCHEDULE-*`, `PR-PROD-*`, and release docs.

MK1 introduces an explicit closure graph instead of relying on chronological reconstruction.
